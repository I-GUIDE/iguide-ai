#
# Why it exists. requirements.txt names 42 packages and pins none of them to a version:
# geopandas, shapely, rasterio, libpysal and pandas are bare names, and the few bounds are lower
# bounds. So until this file, "the deployed stack" was whatever pip happened to resolve on the
# day the image was built, recorded nowhere.
# CI installs through it,
#     pip install -r requirements.txt -c constraints.txt
# so the suite tests the versions that are actually running, not latest-at-run-time.
#
# The images install through it as well. rag_pipeline/Dockerfile, MCP_server/Dockerfile and
# metadata-extraction-server/Dockerfile pass `-c constraints.txt` to every pip install, so a
# rebuild reproduces the versions below instead of resolving that day's newest, and
# rag_pipeline/tests/test_image_installs_through_lock.py fails if one of them stops.
#
# A new requirement floats until this file is retaken. A constraint binds only a name it lists,
# so a package added to requirements.txt after the freeze, and any new dependency it brings,
# resolves at build time to its newest version that fits the pins below. Nothing listed here
# moves to make room: if no version fits, the build fails with ResolutionImpossible. CI's drift
# step names every floating package in a warning. After the deploy that ships it, retake this
# file from the rebuilt container (command below); that pins it and clears the warning. To move
# a listed package on purpose, edit its line here in the same change. A later retake should
# then reproduce this file exactly, apart from packages that floated; any other difference
# means the image did not install what this file says.
#
# Regenerate from the deployment (read-only there), never from a development machine:
#     { sed -n '1,/^# ---- pip freeze/p' constraints.txt
#       ssh exouser@149.165.147.219 'docker exec agent-api python -m pip freeze'
#     } > constraints.new && mv constraints.new constraints.txt
# then update the date, image id, interpreter and count above (the image id is
# `docker inspect --format '{{.Image}}' agent-api` on the same host). A freeze taken on the Mac
# is the trap this replaces: it carries ~/.local packages that a clean build lacks, and it pins
# what the Mac resolved. origin/backend_swap's constraints.txt is one such Mac-frozen lock. It
