# Version lock for reproducible builds.
#
# WHAT THIS PINS
# The stack the DEPLOYED agent-api image runs, from `pip freeze` inside the running container
# on 2026-10-01 (CPython 3.11.16, x86_64). That is the stack the EarthVerse / GeoAnalystBench
# runs measured, so it is the baseline: a lock that differs from it describes an environment
# nobody deploys. Until 2026-10-01 this file instead pinned a dev Mac's stack (pandas 2.2.3,
# numpy 2.1.3, langchain 1.2.10, networkx 3.4.2); building the image from it would have
# downgraded production across a pandas MAJOR version.
#
# WHY A LOCK AT ALL
# requirements.txt carries unbounded pins (`langchain>=1.0`, bare `pandas`), so a clean build
# resolves whatever is newest that day. Measured 2026-08-07: the resolution moved inside one
# afternoon. Nothing measured against a baseline means anything while the stack drifts.
#
# Upgrading is fine, as a deliberate, measured step: bump here, re-run `pytest` and the
# benchmark, and record the delta in docs/DEVLOG.md. Regenerate the generated block below from
# a fresh `pip freeze` of the image rather than editing it by hand.
#
# Usage (both Dockerfiles, CI, and any clean venv):
#   pip install -r requirements.txt -c constraints.txt
